Installation

Clone the repository and run the installer on Arch/CachyOS, supported Debian/Ubuntu derivatives, or Fedora with Plasma 6.

Details & troubleshooting

Does it support Wayland?

Yes. KWin Saturation is a native KWin 6 effect and works with supported KDE Plasma 6 Wayland sessions.

Does it work on Plasma 5?

No. KDE Plasma 6 and compatible KWin 6 development packages are required.

Does it add another shader pass?

No. It uses KWin's existing compositing shader and updates the saturation value for each window during the paint pass. Performance varies with your GPU driver and workload.

What if it stops working after a KWin update?

Rebuild and reinstall against the updated KWin development packages, then log out and back in. See the troubleshooting guide ↗.
