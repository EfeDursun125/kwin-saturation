Installation

Up and running
in a few steps.

For supported KDE Plasma 6 installations on Arch/CachyOS, Debian/Ubuntu derivatives, and Fedora.

01
Get the sourceClone the GitHub repository to your machine.
02
Run the installerIt checks dependencies, builds the effect, and installs the control panel. Read the script before running it.
03
Log out and back inLaunch Digital Vibrance from the application menu. If needed, enable Saturation Boost under Desktop Effects.
Terminal · Quick install
$ git clone https://github.com/EfeDursun125/kwin-saturation.git
$ cd kwin-saturation
$ ./autoinstall.sh
Want to see what the installer would do first? Run ./autoinstall.sh --dry-run.
⚠The automatic installer uses sudo for system changes. On Arch/CachyOS, it also performs a full system package upgrade.
Terminal · CLI examples
# Boost to 125%
kwin-saturation 1.25
# Neutral
kwin-saturation 1.0
# Grayscale
kwin-saturation 0.0

Good to know

Frequently asked questions.

Does it support Plasma 5?

No. KWin Saturation is a KWin 6 native effect and requires KDE Plasma 6 with compatible development packages.

Does it work on Wayland?

Yes. The effect supports Plasma 6 Wayland sessions as well as KWin-supported compositing configurations.

Does it use a custom shader?

No. It changes the saturation value during KWin's existing window paint pass. Performance depends on your desktop workload and graphics driver.

What if it stops working after an update?

KWin APIs can change. Rebuild and reinstall the effect against your updated KWin development packages, then log out and back in. See the troubleshooting guide.
